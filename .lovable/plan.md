# 生物能管平台实施计划

## 目标
打造一个以生物能源运营为核心的六菜单数据平台：固定玻璃导航、鲜明能源背景、高透明毛玻璃卡片、流光边框、强对比数据与差异化页面布局。

## 页面结构
1. **能源总览**：核心指标、能源流向主图、实时负荷、关键站点状态与告警表。
2. **生产监控**：大型趋势图、机组产能排行、运行参数矩阵、设备状态时间线。
3. **原料管理**：库存仓位、原料构成饼图、热值雷达、到货柱线混合图与供应表。
4. **碳效分析**：减排成果、碳效趋势、区域对比、碳流指标与项目清单。
5. **设备运维**：设备健康雷达、风险分布、检修计划、告警队列与在线状态。
6. **经营分析**：收入成本组合图、利润结构、经营指标、项目收益排行与月度明细。

## 视觉与交互
- 深色青绿生物能源主调，辅以荧光绿、青蓝和琥珀色数据强调。
- 自制鲜明的生物能源科技背景，叠加网格、光束与植物/能量意象。
- 卡片采用高透明毛玻璃、细流光渐变边框、柔和内高光与悬浮抬升。
- 顶部固定六菜单导航：左三项、居中大标题、右三项，均为图标加文字。
- 页面切换、图表与状态变化使用克制的淡入和数字脉冲动画，并兼容减少动态效果设置。

## 技术实现
- 使用 TanStack Router 保持单页入口，以菜单状态切换六个完整工作台视图。
- 安装并使用 ECharts React 封装，覆盖折线、柱状、雷达、饼图和混合图；所有折线/混合图图例置顶并预留顶部空间。
- 图表按容器自适应，工具提示、图例和坐标轴统一使用设计令牌。
- 添加页面专属 SEO 标题、描述与社交元数据。
- 完成后检查构建结果，并以桌面与手机视口验证导航、图表、表格和文字无重叠。
